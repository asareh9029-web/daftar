# دفتر دارایی
نسخه مستقل اپ حسابداری شخصی. فایل‌های این پوشه را روی هر هاست استاتیک (مثل GitHub Pages) بگذارید.
`prices.json` قیمت‌های روز است و به‌طور خودکار به‌روز می‌شود.

## دفتر خرید ورس (`/vers`)
ثبت فاکتور خرید، بدهی پخش‌ها و تطبیق صورت‌حساب بانک برای مجموعه ورس. داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند و در این مخزن نیستند؛ برای انتقال داده از «پشتیبان کامل» در تب گزارش استفاده کنید.
